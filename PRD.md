# Campus Insight - Product Requirements Document (PRD)

## Project Description
Campus Insight is a simple web application that helps students access important campus information in one place. The platform allows students to view announcements, upcoming events, and basic academic information.

## Problem
Students often miss important campus updates because information is shared across different channels. Campus Insight provides a central place for students to stay informed.

## Objectives
- Provide campus announcements in one platform.
- Help students stay updated on campus events.
- Make campus information easy to access.

## Target Users
- Students
- Lecturers
- School Administrators

## Features

### 1. Announcements
- View school announcements.
- Display latest updates from lecturers and administrators.

### 2. Campus Events
- View upcoming campus events.
- Display event date and location.

### 3. Student Information
- View basic student profile.
- View enrolled courses.

### 4. Search Function
- Search for announcements and events.

## Functional Requirements
- User login.
- View announcements.
- View events.
- Search information.
- Update announcements (Admin only).

## Non-Functional Requirements
- Easy to use.
- Secure login system.
- Responsive design for mobile and desktop.

## Success Criteria
- Students can easily access announcements.
- Campus events are displayed correctly.
- Users can log in and navigate the system without issues.

## Conclusion
Campus Insight is a simple platform that improves communication between students and the institution by providing a centralized source of campus information.
